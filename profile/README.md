# XIV Hub

Final Fantasy XIV tools and plugins. Home base is [xivhub.net](https://xivhub.net).

## Web tools

- **[EchoPlan](https://echoplan.xivhub.net)**, a raid and encounter planner.
- **[Compare](https://compare.xivhub.net)**, an FFLogs rotation inspector that puts two logs next to each other.

## Dalamud plugin repository

Add this custom repository in Dalamud (`/xlsettings`, Experimental, Custom Plugin Repositories):

```
https://plugins.xivhub.net/pluginmaster.json
```

Plugins in the repo:

| Plugin | What it does |
| --- | --- |
| Ice's Cosmic Exploration (fork) | Cosmic Exploration automation, with relic XP/sec scoring plus "level all crafters" and "farm all relics" modes |
| Artisan (fork) | Crafting automation with better FC Workshop crafting |
| SealHunter | Automates GC and class/job hunting logs |
| AutoPincher | One click retainer undercut, fully local |
| InventoryCleaner | Tidies your inventory automatically |
| FeteTimer | Never miss a Firmament Fête |
| PartyPlanner Reborn | Browse partake.gg events in-client |
